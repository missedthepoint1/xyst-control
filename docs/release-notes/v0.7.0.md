## XYST CONTROL v0.7.0 — UI refresh

A visual + UX polish release. **Camera-control logic is unchanged** (renderer-only); tests + typecheck green across all packages.

### Redesigned dark UI
- New default **Studio** theme — a flat instrument look with a single cyan-teal accent. Dropped the old rainbow-gradient / glow / glassmorphism styling that read as "templated."
- One alternate, **Aurora** (refined dark-modern, single violet accent). The Broadcast / Cinema / Mono / Tactical themes were removed.
- Camera-panel controls are grounded on a recessed control bar with consistently-sized buttons; tighter, evenly-framed spacing around the live view; offline panels size to content instead of ballooning.

### UX
- **Presets** are now created from the panel's gear settings; the panel shows quick-recall chips only.
- The **focus save-point** bar is hidden by default (re-enable per camera under the gear → *Focus points*).
- **Capture devices** are given friendly names (Blackmagic Web Presenter 4K, DeckLink Duo 2); 2×2 quad-crop sources are offered only for multiview-capable devices.
- Added a generic **"Canon XC — other body"** option to Add Camera — works for any Canon cinema body on the XC Protocol (C70, XF605, C500 Mk II…) via capability discovery, no code changes.
- Settings gear icon (was a sun); Aurora theme-select fill fix; misc cleanup.

### Install
Download the `.dmg` below (signed & notarized) → drag to **Applications**. No Gatekeeper prompt. The Windows installer attaches to this release once CI finishes.
